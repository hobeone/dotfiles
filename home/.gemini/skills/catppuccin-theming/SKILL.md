# Catppuccin Theming

Standardized color palette guidelines for Catppuccin themes across terminal, code editor, and desktop applications.

## Palettes Overview

Catppuccin provides 4 flavors:
- **Latte**: Light theme
- **Frappé**: Low-contrast dark theme
- **Macchiato**: Medium-contrast dark theme
- **Mocha**: High-contrast dark theme

## Usage Guidelines

When configuring UI colors or terminal themes:
1. Prefer standard Catppuccin color names (`Rosewater`, `Flamingo`, `Pink`, `Mauve`, `Red`, `Maroon`, `Peach`, `Yellow`, `Green`, `Teal`, `Sky`, `Sapphire`, `Blue`, `Lavender`).
2. Maintain consistent contrast ratios for text readability (`Text`, `Subtext1`, `Subtext0`, `Overlay2`, `Overlay1`, `Overlay0`, `Surface2`, `Surface1`, `Surface0`, `Base`, `Mantle`, `Crust`).
